## 📊 精选项目

### [项目一：金融贷款用户风险特征分析与分层](https://github.com/ChaceXYang/financial-risk-analysis)
&gt; 金融科技 · 风控策略 · SQL + Python

基于天池金融风控数据集（5万条贷款记录），完成风险特征分析与可解释风险分层。

- **SQL深度分析**：运用窗口函数(NTILE/RANK)和多维交叉分析，发现DTI&gt;40%用户违约率是低负债用户的 **3.2倍**
- **核心洞察**：贷款等级G违约率 **28.3%**，是A等级 **3.1%** 的 **9.1倍**；FICO&lt;650用户集中 **58%** 违约案例
- **规则引擎**：基于DTI+FICO+贷款等级设计三层风险分层，覆盖 **76%** 违约案例
- **技术栈**：Python · pandas · matplotlib · SQL · Jupyter Notebook

### [项目二：英国零售客户留存与RFM分层分析](https://github.com/ChaceXYang/ecommerce-rfm-cohort)
&gt; 电商用户增长 · 留存分析 · RFM · SQL + Python

基于UCI Online Retail数据集（54万条交易记录），构建RFM客户分层模型与同期群留存分析。

- **RFM分层**：识别出 **8.2%** 重要价值客户贡献 **44.5%** 营收，**11.8%** 重要挽留客户是运营重点
- **同期群分析**：1月获取客户6个月留存率 **35%**（质量最佳），12月促销获客留存率仅 **15%**（羊毛党多）
- **业务建议**：针对挽留客户设计定向优惠券（预计挽回 **20%** 流失营收），减少12月促销预算转向精准获客
- **技术栈**：Python · pandas · seaborn · SQL(窗口函数) · Jupyter Notebook
