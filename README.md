## Featured Project — H&M Customer Retention & RFM ✅

**Business question:** is this e-commerce business driven by repeat customers or one-time buyers? *(30M+ real transactions, 3.7GB, 2018–2020)*

| Finding | Business action |
|---|---|
| Repeat customers (64% of users) drive **94% of revenue** | Push 2nd purchase within 30 days of first order |
| First-month retention drops to **44%** | Fix new-user activation window (month 1) |
| Top-3 apparel categories = **79% of revenue** | Concentrate inventory & campaign budget on core apparel |
| Dormant customers (46% of users) = only **18% of revenue** | Selective reactivation, not mass campaigns |

**How it was built:** chunked a 3.7GB CSV → 6.2M-row customer×month table (SQLite) → 5 SQL analyses (cohort retention, RFM segmentation, repeat-purchase structure, category Pareto, dormant customers) → 3 visualizations. Full [repo](https://github.com/ChaceXYang/analytics-lab/tree/main/projects/hm-customer-retention-rfm) with a complete README report.
